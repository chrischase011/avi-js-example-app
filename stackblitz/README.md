# Avi.js starter

The app `npm create avi@next` makes (modular template), ready to run on
[StackBlitz](https://stackblitz.com/github/chrischase011/avi-js-example-app/tree/main/stackblitz?file=src/modules/users/users.controller.ts&initialpath=/users).
Users are kept in memory. `.stackblitzrc` installs and runs `npm run dev`.

```sh
npm install
npm run dev     # compile and restart on change
npm test        # compile and run the tests
npm run build   # update the generated files and compile to dist/
npm start       # run the compiled app
```

Then open http://localhost:3000/health and http://localhost:3000/users.
